# Atividade 06 - TDD: Validador de Senha

Projeto em Java para validar os requisitos de senha da atividade prática de TDD.

## Requisitos

A senha precisa:

- Ter pelo menos 8 caracteres.
- Conter pelo menos 2 dígitos.
- Conter pelo menos uma letra maiúscula.
- Conter pelo menos um caractere especial.

O validador retorna um resultado booleano indicando se a senha é válida e uma lista com todos os erros encontrados.

## Como executar os testes

É necessário ter Java 17 e Maven instalados. Na pasta do projeto, execute:

```bash
mvn test
```

## Commits

O histórico segue o padrão indicado para a atividade, com commits separados para configuração, testes, implementação e documentação.
